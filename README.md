<h1> Paw R Us SA</h1>

  Paw R Us SA is a non-profitable organisation that specialises in saving,sheltering and caring for stray and abandoned dogs. <br>
  Thus, as a web developer, for the POE I have chosen an organization that has no website, but the organization itself remains in existence and that way 
  many of information used to create the website comes from the available information on the internet about the NPO.
